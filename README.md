## 新玩法：任务模式
- 左上角新增「🏁 任务」按钮，点一下开始、再点退出。
- 一圈 8 个检查点计时挑战：当前检查点是一根冲天光柱（最后一个是金色），顶部任务条显示进度、下一个点距离、用时和本图最佳成绩。
- 跑满一圈结算总用时和平均速度；最佳成绩按地图存档，下次自动显示。逆行、扶车传送都不会刷分。任何地图都能玩。

## 新乘客：后座 JK 妹子
- 左上角「👧 后座」按钮（默认关，点开才加载人，状态会记住）。她坐在后座扶着驾驶员腰侧，过弯时上身会慢半拍侧倾、头会自己找平，有真人那种轻微晃动感。
- **说实话的部分**：游戏自带的女性模型是一整张贴图的单个模型，上衣颜色没法单独改（还是原来的黄色上衣）。JK 感靠外挂三件套：藏青格纹裙（canvas 画的格纹）、红色领结、黑色长袜套筒。裙摆和袜筒的比例没法在这边真机预览，可能有轻微穿插——你打开看一眼，哪里不对告诉我，我再调。
- **驾驶员"更灵活"没做**：驾驶员模型在游戏里被烘焙成静态网格，逐帧转头画面根本不会动；硬做必须改游戏核心循环，容易连累别的功能。这次没冒险，理由放这儿，等你定。
